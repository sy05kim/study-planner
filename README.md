# AI 학습 플래너

## 1. 프로젝트 소개

AI 학습 플래너는 사용자가 과목, 학습 목표, 학습 기간, 하루 공부 가능 시간을 입력하면 맞춤형 학습 계획을 생성해주는 웹 서비스입니다.

학생들이 막연하게 공부를 시작하는 것이 아니라, 목표와 기간에 맞춰 체계적으로 학습할 수 있도록 돕는 것을 목표로 합니다.

## 2. 제작 목적

많은 학생들이 공부 계획을 세우는 데 어려움을 겪습니다.  
이 서비스는 사용자의 입력값을 바탕으로 학습 일정을 자동으로 정리해주어 효율적인 학습을 도와줍니다.

## 3. 주요 기능

- 과목 입력 기능
- 학습 목표 입력 기능
- 학습 기간 입력 기능
- 하루 공부 가능 시간 입력 기능
- 입력값을 기반으로 학습 계획 생성
- 생성된 학습 계획을 카드 형태로 출력
